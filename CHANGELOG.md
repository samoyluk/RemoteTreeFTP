# Changelog

## 0.1.1 — 2026-10-15

- Move Keychain helpers into an internal subpackage to follow Sublime plugin import rules.
- Add direct settings entries to the command palette and Preferences → Package Settings.
- Validate internal imports from a packed distribution.

## 0.1.0 — 2026-10-14

Initial public release candidate: FTP/explicit FTPS tree, profile wizard,
English/Russian UI, optional macOS Keychain, numeric permissions, file operations,
conflict checks, ten local pre-upload backups per file and manual restoration.
Settings open in the standard split view. macOS is the initial supported platform.
